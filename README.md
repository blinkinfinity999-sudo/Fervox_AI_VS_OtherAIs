# ⚡ Fervox AI Latency & Speed Benchmark Tool

An interactive, client-side web utility designed to measure and prove the raw performance differences between corporate AI wrapper dashboards and optimized edge routing pipelines. 

This second website complements the main Fervox comparison page by acting as a highly functional, developer-focused utility that visually drives home the **1.5x speed advantage** through real-time telemetry simulations and live endpoint evaluation tracking.

## ✨ Features

* **⏱️ Real-Time Telemetry Interface:** Beautiful terminal-style UI metrics cards showing Time-To-First-Token (TTFT) in milliseconds, complete with matching progress load behaviors.
* **🔒 Pure Client-Side Security:** Input fields run entirely in the browser memory context, ensuring corporate keys are processed securely with zero server-side harvesting hooks.
* **🖥️ Live Logging Simulator Console:** A simulated system diagnostic console box running instant status log alerts to mimic native command-line tool feedback environments.
* **🧭 Integrated Referral Loops:** Clear internal page Call-To-Action frameworks routing users straight back to your primary `index.html` comparison layouts.
* **📱 Ultra-Lightweight Footprint:** Built inside full developer monospace system layouts to load instantaneously on Vercel Edge networks without framework bundle delays.

## 🛠️ Customizing the Diagnostic Logic

If you want to alter or fine-tune the simulated performance latency metrics to accurately match specialized internal cluster benchmarks, adjust the mathematical range limits located directly inside line 23 of the `speed-script.js` file:
```javascript
// Baseline calculations for the 1.5x Edge connection speed
const fervoxTTFT = Math.floor(Math.random() * (180 - 120) + 120); // Edit raw min/max ms variables here
const standardTTFT = Math.floor(fervoxTTFT * 1.5);               // Adjust the 1.5x multiplier constraint
```
